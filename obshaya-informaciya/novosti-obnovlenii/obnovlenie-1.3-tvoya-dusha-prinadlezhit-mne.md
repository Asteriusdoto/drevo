# Обновление 1.3 - Твоя душа принадлежит мне

## Изменения в пвп, броне и оружии

Описание и особенности новой брони души

Уникальные способности брони:

Броня с дремлющей душой(Т1), Броня с осознанной душой(Т2), Броня с пробудившейся душой(Т3), Броня пронизанная душой(Т4): в полном сете могут использовать все виды оружия + работают уникальные механики, а именно регенерация 1 и скорость 1 пока надет полный сет брони души



Броня души (тира Т5) - обладает двумя дополнительными уникальными механиками при полном комплекте:

Сразу указываю нюанс!

Пример 1:

На человека одет следующий сет брони:

Шлем души

Нагрудник пронизанный душой

Поножи души

Ботинки души

В таком сете будет работать только первая (реген) и вторая (скорость) уникальные механики , т.к. на игрока НЕ надет полный комплект именно брони души тира Т5. В таком наборе он все также может использовать любые виды обычного оружия.

Пример 2:

На человека одет следующий комплект брони:

Шлем души

Нагрудник души

Поножи души

Ботинки души

В таком комплекте уникальные механики работают все (т.к. на игрока надет полный набор именно пятого тира) + игрок может использовать любые виды оружия.

Уникальные механики брони души финального тира:

1\. Перманентный эффект регенерации 1

2\. Перманентный эффект скорости 1

3\. Уменьшает конечный(финальный) урон по игроку в данном комплекте в 2 раза.

4\. Можно пользоваться оружием души: Меч души и Арбалет души.

Пример:

Игрок одет в следующий комплект:

Шлем души

Нагрудник души

Поножи души

Ботинки души

У игрока действуют 4 баффа перечисленные выше. Как только игрок заменил хотя бы одну часть комплекта на какую-либо другую или вовсе снял одну из частей, баффы сразу  будут переставать работать.

#### Изменения механики урона трезубца

Изменена механику урона при броске трезубца\
Сейчас работает примерно следующим образом:\
Пример:\
Урон атакующего:\
28 - урон трезубца\
+1 - от технологии будущего\
+5 - катализаторы урона\
+1 - нация\
+1 - чудо света\
Итого: 36

Броня атакуемого:\
23 - полный комплект тяжелой Т4 брони\
+1 - нация\
+1 - чудо света\
Итого: 25

При броске, начальный урон трезубца \* 1.3\
Таким образом урон при броске будет следующим\
28 \* 1.3 + 1 + 5 + 1 + 1\
Итого: 44,4

Таким образом, в данном примере, конечный урон по человеку при броске трезубца с полной натяжки будет:\
44,4 - 25 = 19,4

В ходе тестов система показала погрешности и сложность логики получения конечного урона.\
Систему решено было изменить. Теперь механика при броске будет следующая.\
урон + 5 + количество урона от катализаторов / 2\
Пример:\
Урон атакующего:\
28 - урон трезубца\
+1 - от технологии будущего\
+7 - катализаторы урона\
+1 - нация\
+1 - чудо света\
Итого: 36

Броня атакуемого:\
23 - полный комплект тяжелой Т4 брони\
+1 - нация\
+1 - чудо света\
Итого: 25

При броске должно считать следующим образом:\
28 + 5 + 7/2(7 - количество доп. урона от катализаторов) + 7 + 1 + 1 + 1\
Итого: 46.5\
Таким образом, в данном примере, конечный урон по человеку при броске трезубца с полной натяжки будет:\
46.5 - 25 = 21.5
